# ממשק Ofir — סבב חוויית שימוש ועיצוב

## מה השתנה

ממשק בהיר עם גופן Heebo משתנה שמאוחסן בפרויקט, רוחב קריאה מוגבל, היררכיית טקסט עקבית וכרטיסי משרה צפופים יותר. ברשימה, שם החברה, התפקיד והמיקום מיושרים יחד גם בטקסט אנגלי; ציון ההתאמה נשאר ממד נפרד ממצב האימות ותנאי הסף. סיכומים קצרים מחליפים אריחי סטטיסטיקה גדולים. החיפוש קודם למסננים גם בסדר המקלדת ולא רק במראה. במובייל הניווט הראשי עובר לסרגל תחתון, וחלונית המשרה תופסת את המסך.

## חלונית המשרה

`components/job-details.tsx` מחליף את החלונית שהייתה מוטמעת במסך הראשי. ברירת המחדל היא תיאור המקור; התאמה ופערים והמעקב האישי נמצאים בלשוניות נפרדות. פירוט הציון ותאריכים נוספים נגישים בהרחבה. כותרות מוכרות בטקסט המקור מוצגות כהיררכיית כותרות ללא יצירה או השלמה של דרישות. אין רינדור HTML לא מהימן.

פעולות פתיחת המקור ושמירה להמשך נראות בתחתית גם בעת גלילת תיאור ארוך. אפשר לעבור בין המשרות שנמצאות בסינון הנוכחי. שינוי סימון שמוציא משרה מהסינון אינו מחליף את המשרה הפתוחה באופן מפתיע.

הכשל המקורי נבע מאירועי לחיצה: `showModal()` הופך את התוכן שמחוץ ל־dialog לבלתי פעיל, ולכן מעטפת רקע חיצונית לא קיבלה את הלחיצה. כעת ה־dialog עצמו מכסה את המסך ובתוכו לוח התוכן. לחיצה שמתחילה ומסתיימת בשטח שמחוץ ללוח סוגרת אותו; לחיצה פנימית או גרירה שהחלה בתוך הלוח אינן סוגרות. Escape וכפתור הסגירה פועלים גם כשהשמירה מתבצעת. נעילת גלילת הרקע משתחררת ומוקד המקלדת חוזר לכפתור הפותח, או לתוכן הראשי אם המשרה כבר יצאה מהסינון.

## שמירה, טיוטות ונגישות

סימונים ומצב מועמדות נשמרים דרך אותו API, עם ביטול שינוי אופטימי והודעת שגיאה במקרה של כשל. טיוטת הערה נשמרת בזיכרון המרחב לפי מזהה משרה גם אחרי סגירה ופתיחה או מעבר למשרה אחרת. שמירה למאגר דורשת לחיצה מפורשת; הדף מסביר שהטיוטה אינה נשמרת אחרי רענון. טיוטה נמחקת רק לאחר אישור שמירה מהשרת.

לשוניות תומכות בחצים, Home ו־End. סדר המוקד נשאר בתוך החלונית עם Tab ו־Shift+Tab. קיימים מצבי מוקד, תוויות לפקדים והודעות שמירה. שבעה זוגות צבעי טקסט/רקע שנבדקו בחישוב עברו יחס 4.5:1. זו אינה הצהרת הסמכה מלאה ל־WCAG; לא בוצעה בדיקת קורא מסך ידנית בכל הדפדפנים.

עקרונות ההתנהגות נבדקו מול [דפוס Dialog Modal של WAI-ARIA](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/), שקוד המקור שלו נקרא מ־[מאגר W3C](https://github.com/w3c/aria-practices/blob/main/content/patterns/dialog-modal/dialog-modal-pattern.html). ניסיון לקרוא ישירות את HireMeTech ואת עמודי התיעוד ברשת נחסם ב־403; אין כאן טענה שהאתר נבדק חזותית או הועתק.

## קבצים וגבולות

- `components/dashboard.tsx`: מצב החיפוש, הסימונים והטיוטות; פתיחת רכיב פרטי המשרה.
- `components/job-details.tsx`: חלונית, לשוניות, גלילה, מוקד ופעולות אישיות.
- `components/job-views.tsx`: כרטיסי משרות ומעקב המועמדויות.
- `app/globals.css`: מערכת העיצוב והתאמות המסכים, גם למסכי חברות וייבוא.
- `app/layout.tsx`, `app/fonts/`: גופן מקומי באמצעות `next/font/local`; רישיון OFL מצורף. אין בקשת גופן ל־Google בזמן שימוש באתר.

לא שונו פרופיל הניסיון, הציונים, כללי ההמלצות, סכמת הנתונים, הרשאות הגישה, מנגנון האיסוף או לוחות הזמנים. ניווט ומסננים עדיין אינם נשמרים בכתובת; טיוטות הן זמניות ולא תחליף לשמירה במאגר.

- `npm run typecheck`: עבר.
- `VERCEL=1 OFIR_STORAGE=supabase npm run build`: עבר.
- צולמו ונבדקו תצוגות ב־1440×900, 1280×800, 1024×768, 768×1024 ו־390×844. הצילומים נוצרו ממסד בדיקות מבודד עם נתונים סינתטיים, לא מחשבונו האישי של אופיר.
- מחוון הפיתוח של Next מוסתר בבדיקות בלבד, כדי שלא יכסה כפתורי ניווט במובייל; הצגת שגיאות הפיתוח לא כובתה.
