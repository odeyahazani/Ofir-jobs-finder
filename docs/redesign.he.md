# עיצוב ממשק — אוקטובר 2026

הממשק מכוון לגילוי משרות ולקבלת החלטות: ניווט לבן מימין, רקע אפור קריר, טקסט כהה ופעולות כחולות. משתני הצבע, הריווח והמצבים מרוכזים ב־`app/globals.css`. נעשה שימוש בגופני מערכת עם תמיכה בעברית; אין טעינת גופנים משירות חיצוני.

## מבנה והתנהגות

- `components/dashboard.tsx`: ניווט, סינון, שמירה ופרטי משרה. סיכומים קטנים ולחיצים מחליפים באנרים וכרטיסי סטטיסטיקה גדולים. מידע על בריאות האיסוף עבר למסך החברות. רכיבים שמרמזים על התראות או תזמון שאינם מאומתים הוסרו.
- `components/job-views.tsx`: כרטיסי משרות עם שמירה, העדפת אי־התאמה וסימון היכרות. הטבלה למועמדויות מאפשרת עדכון הסטטוסים הקיימים; בתצוגת מובייל היא נערמת לשורות עם תוויות. שמירה להמשך משתמשת ב־`fit=yes`, כפי שהיה בסינון השמורות. ביטול שמירה אינו מבטל היסטוריית מועמדות; משרות בתכנון הגשה מנוהלות דרך סטטוס המועמדות.
- `components/job-ui.tsx`: תוויות, ציונים ואימות משותפים. אימות ישן מ־30 שעות מצוין כדורש רענון; זמינות, תנאי סף והתאמה מקצועית מוצגים בנפרד. קישור המקור נמצא בתחילת חלונית הפרטים.
- `components/companies-list.tsx`: חיפוש, מסנני מעקב ובריאות מקורות, תוצאות סריקה ומתגי המעקב הקיימים.
- `components/import-panel.tsx`: הוספת נתונים, בדיקה מקדימה ואישור. פירוט הפורמט מוסתר בהרחבה. רשומות מיובאות נשארות ממתינות לאימות.

## החלטות וגבולות

לא השתנו סכמות, ספי דירוג, חוזי API, הרשאות, מנגנון האיסוף, תזמון או משלוח התראות. הסינון לישראל נשאר ברירת המחדל; המועמדויות נשארות זמינות מכל המיקומים. מיון התאמה מציג כעת ציון יורד מדויק במקום קיבוץ לעשרות. המסנן החדש נקרא ״חדשות ב־24 שעות״ בהתאם לחלון הזמן המתגלגל.

תאריך הגשת מועמדות אינו זמין במודל המשרה של הממשק, ולכן לא מוצג תאריך משוער. לא נוספו סיווגי תחום או אזור לא מבוססים, מסכי קנבן או מצבי תצוגה חלקיים. הניווט והמסננים נשארו במצב React מקומי ואינם נשמרים בכתובת; קישורים שמורים והיסטוריית ניווט הם הרחבה עתידית נפרדת.

יש מוקד מקלדת ברור, דילוג לתוכן, תוויות למתגים ולכפתורים, הודעות שמירה ושגיאה, חלונית עם Escape והחזרת המוקד לכפתור הפותח. העיצוב משתמש בזוגות צבע עם ניגודיות גבוהה. בדיקות דפדפן אינן מהוות אישור נגישות WCAG מלא או תחליף לבדיקת קורא מסך ידנית.

צילומי המסך נוצרו מנתוני בדיקה מבודדים, לא מחשבונו או מנתוניו האישיים של אופיר.

## בדיקות שבוצעו

- `npm run typecheck` — עבר.
- `npm test` — עברו 59 בדיקות Python ו־28 בדיקות Node/PostgreSQL.
- `npm run test:e2e` — עברו תשע בדיקות, כולל בדיקות השמירה, הייבוא, הסינון וההרשאות הקיימות, פעולות מהירות, שחזור אחרי כשל שמירה, Escape והחזרת מוקד.
- `VERCEL=1 OFIR_STORAGE=supabase npm run build` — עבר.
- תצוגות נבדקו וצולמו ב־1440×900, 1280×800, 1024×768, 768×1024 ו־390×844. נבדק היעדר גלישה אופקית בכל ארבעת המסכים; המשרה הראשונה במחשב מתחילה לפני פיקסל 450.
- בדיקת חישוב יחס הניגודיות של שמונה זוגות טקסט/רקע עברה עם יחס של 4.78:1 ומעלה. צבע הטקסט המשני הוכהה מעט ביחס לפלטת ההתחלה לשם כך.
- אין בדיקה עצמאית של כניסה לחשבון המשתמש או של פריסת Vercel לאחר הדחיפה.
