# תוספת מוצעת להוראות משימת הגילוי בצ׳אט

אפשר להוסיף את הטקסט הבא להוראות הקיימות, תוך שמירה על פרופיל אופיר והסינונים שכבר הוגדרו:

> מטרת החיפוש היא להרחיב בהדרגה את מאגר החברות הרלוונטיות ואת מאגר המשרות לאופיר כהן. המשיכי לחפש חברות חדשות לצד משרות בחברות שכבר מוכרות, עם עדיפות למקורות רשמיים ולתפקידים מעשיים בתחומי הנדסת חשמל, פיזיקה, מכשור רפואי, אופטיקה, אינטגרציה ובדיקות.
>
> בנוסף להתראה הרגילה, החזירי ממצאים חדשים בפורמט JSON תקין, ללא הערות בתוך ה־JSON, עם שני מערכים: companies ו־jobs. אפשר להחזיר קובץ JSON להורדה אם קיימת היכולת, או מקטע JSON שאפשר להעתיק. בכל מנה עד 100 רשומות בסך הכול.
>
> כל רשומת חברה תכיל name, career_url, location, notes. השתמשי בשם חברה עקבי. notes יכיל הסבר קצר להתאמה לאופיר ומקור למידע. career_url הוא קישור לאתר הקריירה הרשמי אם נמצא; אם לא נמצא, השאירי מחרוזת ריקה וצייני זאת בהערות. עצם הוספת חברה אינה ראיה למשרות פתוחות.
>
> כל רשומת משרה תכיל company, title, url, location, notes. נדרשים חברה, כותרת וקישור ספציפי למשרה. עדיף לצרף גם רשומת חברה עם קישור הקריירה שלה. notes יסביר בקצרה התאמה ופערים, ואם אין אימות או תאריך פרסום ידוע — יציין זאת במפורש. אין להמציא משרה, כתובת, תאריך או דרישה.
>
> הממשק יקבל את המשרות כממתינות לאימות, והסורק יבדוק אותן במקור הרשמי. אל תטעני שמידע נשמר באתר בלי שקיימת יכולת חיבור מורשית והתקבל אישור הצלחה מהממשק. אם אין למשימה אפשרות לבצע כתיבה חיצונית, החזירי את ה־JSON לייבוא ידני; אל תדמי שליחת בקשה. אין לבקש או לכלול סודות, סיסמאות או מפתחות מנהל בתוכן המשימה.

מבנה ריק לדוגמה:

```json
{"companies": [], "jobs": []}
```

אפשר גם CSV בכותרות:

```csv
kind,company,career_url,title,url,location,notes
```

`kind` הוא `company` או `job`. ערכים הכוללים פסיקים צריכים מרכאות. שמות תפקידים נשמרים באנגלית, והערות יכולות להיות בעברית. חזרות על אותה משרה אינן יוצרות התראה חדשה.

## הממשק המשותף

- בעל החשבון יכול לייבא דרך המסך „ייבוא ממצאים” באתר לאחר התחברות Google. האתר מציג תצוגה מקדימה לפני שמירה.
- מפיק נתונים מורשה שרץ בסביבה נפרדת יכול להשתמש באותו JSON דרך `python -m collector.cloud import-discoveries file.json`, או ב־Supabase RPC `ofir_add_discoveries` עם גוף `{ "payload": ... }`. נדרש אימות תקין של אופיר או עובד איסוף מהימן. מפתח המנהל של עובד האיסוף נשמר בסביבה המאובטחת שלו, ולא בהוראות הצ׳אט.
- הממשק אינו ממשק ציבורי פתוח לכתיבה. משימת ChatGPT מתוזמנת אינה מחוברת אליו רק משום שהיא משתמשת באותו פורמט. אין כאן יכולת לקרוא או לשנות את המשימה המתוזמנת של המשתמשת.
- יצירת חברות חדשות מגיעה מהמשימה/חיפוש חיצוני/הוספה ידנית. ההרחבה האוטומטית של הסורק מוסיפה בהדרגה מעקב אחר חברות שכבר נמצאות במאגר; היא אינה מבצעת חיפוש אינטרנט כללי או רוכשת שירות AI.
